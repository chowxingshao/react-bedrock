# Shared hooks

Hooks used by more than one feature live in `src/hooks/`, one per file, and are imported by file: `import { useDebounce } from '@/hooks/use-debounce';`.

| Hook                   | Signature                                                                                | What it does                                                                                                                                                                                                                                             |
| ---------------------- | ---------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `useDebounce`          | `useDebounce<T>(value: T, delayMs = 300): T`                                             | Returns the latest `value` once it has stopped changing for `delayMs` (search-as-you-type)                                                                                                                                                               |
| `useDisclosure`        | `useDisclosure(initial = false)` → `{ isOpen, open, close, toggle, setOpen }`            | Open/closed state for dialogs, sheets, popovers and menus; the callbacks are stable                                                                                                                                                                      |
| `useMediaQuery`        | `useMediaQuery(query: string): boolean`                                                  | Whether a CSS media query matches, e.g. `'(min-width: 48rem)'`; re-renders when it changes                                                                                                                                                               |
| `useCopyToClipboard`   | `useCopyToClipboard(resetMs = 2000)` → `{ copied, copy }`                                | `copy(text)` writes to the clipboard and resolves `true`, or `false` (no throw) when there is no clipboard or the write is refused; `copied` stays `true` for `resetMs`                                                                                  |
| `useOnlineStatus`      | `useOnlineStatus(): boolean`                                                             | Whether the browser believes it is online (`navigator.onLine`); re-renders on the `online` and `offline` events                                                                                                                                          |
| `useDocumentTitle`     | `useDocumentTitle(title: string \| undefined): void`                                     | Sets the tab title to `<title> · <app name>`, or to the app name alone when `title` is `undefined`. `RootLayout` calls it with the route's title (docs/routing.md)                                                                                       |
| `useDebouncedCallback` | `useDebouncedCallback(callback, delayMs = 300)` → `{ run, cancel }`                      | `run(...args)` calls the latest `callback` once calls stop for `delayMs`; `cancel()` drops a pending call; the timer is cleared on unmount. For committing a search box to the URL (docs/routing.md), where `useDebounce` would debounce a value instead |
| `useFeature`           | `useFeature(flag: FeatureFlag): boolean`                                                 | Whether a feature flag is on; re-renders if a live flag source changes. Flags and their defaults are in `src/config/features.ts`                                                                                                                         |
| `useGsap`              | `useGsap(factory, options?)` with `options` `{ scope?, dependencies?, revertOnUpdate? }` | Optional GSAP animation that runs only when motion is allowed (see below)                                                                                                                                                                                |

**`useGsap`** (`@/hooks/use-gsap`) wraps `@gsap/react`'s `useGSAP`. It runs `factory` only under `(prefers-reduced-motion: no-preference)`, inside a `gsap.context` scoped to a ref that reverts every animation when the component unmounts (or, with `dependencies`, before each re-run). Under reduced motion it does nothing, so write the animation so the un-animated DOM is the final state. Pass a `scope` ref and target elements inside it with selectors (`.box`) or refs. `gsap` and `@gsap/react` are dependencies, but nothing imports them by default, so they are tree-shaken out of the bundle unless a project uses this hook. Use it only for orchestration the CSS motion utilities cannot express (docs/design-system.md, "Motion"); see GSAP's [React guidance](https://gsap.com/resources/React/) for refs, contexts and cleanup.

```tsx
const root = useRef<HTMLDivElement>(null);
useGsap(() => gsap.from('.box', { y: 16, opacity: 0, stagger: 0.05 }), { scope: root });
```

Feature flags are turned on with `VITE_FEATURE_FLAGS="itemsExport,otherFlag"` (build time or container start). Outside React, for instance in a route definition, call `isFeatureEnabled(flag)` from `@/config/features`. To read flags from somewhere else (a remote flag service), call `setFeatureFlagSource(source)` from `@/config/features` before the app renders, in `main.tsx`: components that are already mounted do not switch to a new source until they re-render (a live source notifies them through its `subscribe`). `createEnvFlagSource` can only turn flags on, so a flag whose default is `true` cannot be turned off through `VITE_FEATURE_FLAGS`, and a name it does not know is ignored.

`useUrlState`, `usePagination` and `useUnsavedChangesWarning` are in `src/hooks/` too. They depend on the router, so they are documented in docs/routing.md.
